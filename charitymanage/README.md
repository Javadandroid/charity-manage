# سیستم مدیریت رویداد خیریه (نسخه مدرن)

این سیستم یک پلتفرم پیشرفته و مقیاس‌پذیر برای مدیریت غرفه‌ها، محصولات، فاکتورها، و نوبت‌دهی (همراه با خواندن صوتی اعداد با هوش مصنوعی) برای خیریه‌ها است.

## معماری سیستم

این سیستم به دو بخش اصلی تقسیم شده است:
1. **بک‌اند (Backend):** نوشته شده با فریم‌ورک `Django 6.0` و `Django REST Framework`. معماری نرم‌افزار به سمت Service Layer (الگوی طراحی Clean) حرکت کرده تا منطق پیچیده‌ی کسب‌وکارهایی نظیر اتصال به کارتخوان (POS) و گرفتن گزارش‌های جامع از فایل‌های View خارج شود.
2. **فرانت‌اند (Frontend):** نوشته شده با استفاده از `React` (بر پایه Vite) همراه با استایل‌دهی مدرن `Tailwind CSS v4`. تمامی صفحات، Responsive بوده و رابط کاربری بسیار تمیز، چشم‌نواز و Dynamicی برای نوبت‌دهی کیوسک طراحی شده است.

## ویژگی‌های اصلی
- **تکنولوژی‌های روز:** استفاده از PostgreSQL 19، Django 5 و Vite (React) و سیستم مدیریت State با Zustand.
- **انتقال هوشمند رویدادها:** قابلیت کپی اطلاعات غرفه‌ها، محصولات و پوزها به همراه تغییر قیمت در رویداد جدید به صورت مرحله به مرحله (Wizard).
- **لایه سرویس مستقل:** پیاده‌سازی سرویس‌هایی مانند `POSService` برای مدیریت پرداخت‌های TCP/Serial و `ReportService` برای ساخت فایل‌های اکسل پیشرفته.
- **کیوسک هوشمند نوبت‌دهی:** صفحه هوشمند کیوسک در فرانت‌اند که فاکتورهای "در حال آماده‌سازی" و "آماده تحویل" را نمایش می‌دهد.
- **خواندن صوتی فارسی (آفلاین):** هر بار که فاکتوری آماده می‌شود، شماره فاکتور و نام غرفه به صورت هوشمند و به صورت آفلاین با زبان فارسی خوانده می‌شود (یکپارچه با پکیج persianttsfarsi و gtts).
- **داشبورد مدیریت یکپارچه:** امکان دانلود سریع تمامی گزارش‌های بازارچه، محصولات پرفروش، و شماره موبایل خریداران.

## پیش‌نیازها
- داکر (Docker) و Docker Compose.

## راه‌اندازی سریع با داکر

وارد پوشه پروژه شوید و کانتینرها را اجرا کنید:

```bash
docker-compose up -d --build
```

این دستور به طور همزمان دیتابیس PostgreSQL، بک‌اند (Django) و فرانت‌اند (React) را بیلد و اجرا می‌کند.

اگر از دستگاه پوز متصل به سریال استفاده می‌کنید، می‌توانید در فایل `docker-compose.yml` کامنت مربوط به map کردن پورت سریال (مثلاً `/dev/ttyUSB0`) را حذف کنید.

پس از بالا آمدن داکر:
- آدرس بک‌اند و پنل ادمین: `http://localhost:8000`
- آدرس داشبورد و کیوسک (فرانت‌اند): `http://localhost:3000` (قابل دسترس در شبکه محلی)

برای اعمال تغییرات اولیه دیتابیس (Migrations):
```bash
docker-compose exec backend python manage.py migrate
docker-compose exec backend python manage.py createsuperuser
```

## ساختار پوشه‌ها
- `/backend`: شامل پروژه جنگو، تنظیمات DRF، و اپ‌های `core`, `booths`, `events`, `invoices`, `products`, `reports`, `kiosk`.
- `/frontend`: شامل پروژه ریکت، کامپوننت‌های داشبورد، کیوسک نوبت‌دهی، و فایل‌های استایل Tailwind.
