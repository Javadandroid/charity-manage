# سیستم مدیریت رویدادهای خیریه

سیستم مدیریت رویدادهای خیریه یک نرم‌افزار تحت وب است که برای مدیریت رویدادهای خیریه، غرفه‌ها، محصولات و فاکتورهای فروش طراحی شده است.

## امکانات

- مدیریت رویدادهای خیریه
- مدیریت غرفه‌های هر رویداد
- مدیریت محصولات هر غرفه
- ثبت و مدیریت فاکتورهای فروش
- چاپ فاکتورها
- داشبورد آماری و نمودارها
- مدیریت دسترسی کاربران
- رابط کاربری واکنش‌گرا، مناسب برای مرورگرهای موبایل

## نیازمندی‌ها

- Python 3.8+
- Django 5.2+
- SQLite (پیش‌فرض) یا PostgreSQL (توصیه شده برای محیط تولید)

## راه‌اندازی

### 1. نصب پیش‌نیازها

```bash
pip install -r requirements.txt
```

### 2. مهاجرت پایگاه داده

```bash
python manage.py migrate
```

### 3. ایجاد کاربر مدیر

```bash
python manage.py createsuperuser
```

### 4. جمع‌آوری فایل‌های استاتیک (برای محیط تولید)

```bash
python manage.py collectstatic
```

### 5. اجرای سرور توسعه

```bash
python manage.py runserver 0.0.0.0:8000
```

## دسترسی به سیستم

پس از راه‌اندازی، می‌توانید به آدرس‌های زیر دسترسی داشته باشید:

- صفحه اصلی: `http://localhost:8000/`
- پنل مدیریت: `http://localhost:8000/admin/`

## ساختار سیستم

سیستم از چهار ماژول اصلی تشکیل شده است:

1. **events**: مدیریت رویدادها
2. **booths**: مدیریت غرفه‌ها
3. **products**: مدیریت محصولات
4. **invoices**: مدیریت فاکتورها

## مدیریت کاربران

- فقط مدیر سیستم (superuser) می‌تواند کاربران جدید ایجاد کند.
- مدیر می‌تواند از طریق پنل مدیریت، دسترسی‌های مختلف را به کاربران اختصاص دهد.
- کاربران به سه گروه تقسیم می‌شوند: مدیران سیستم، مدیران غرفه و کارکنان غرفه.

## استفاده در شبکه محلی

برای استفاده از سیستم در شبکه محلی، سرور را با دستور زیر اجرا کنید:

```bash
python manage.py runserver 0.0.0.0:8000
```

سپس می‌توانید با استفاده از آدرس IP سرور و پورت 8000 از دستگاه‌های دیگر به سیستم دسترسی داشته باشید:

```
http://IP-ADDRESS:8000
```

## مهاجرت به PostgreSQL (اختیاری)

برای استفاده از PostgreSQL به جای SQLite، ابتدا PostgreSQL را نصب کنید، سپس تنظیمات پایگاه داده را در فایل `settings.py` تغییر دهید.
